# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.0 | :white_check_mark: |
| < 0.1.0  | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do NOT create a public GitHub issue.

Instead, please report it privately:
- Through GitHub Security Advisories: open a private report via the **Security** tab -> **Advisories** -> **Report a vulnerability**.
- Or email the repository maintainers directly.

### What to include in your report:
- A description of the issue and potential impact
- Affected component or route (e.g. `/v1beta/...`, `/admin/...`, OAuth session management)
- Reproduction steps or proof of concept
- Any potential remediations or workarounds you have identified

### What to expect:
- A response acknowledging receipt of your report within 48 hours.
- A timeline for validation and developing a patch.
- Coordinated disclosure once the patch has been released.
